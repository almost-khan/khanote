# khanote

通用研究工作流工具包，连接 vibe coding 工具与 Obsidian。

[English](README.md)

---

## khanote 是什么？

khanote 将你的 vibe coding 工具（Claude Code / Cursor / Windsurf / Copilot）与 Obsidian 连接起来，中间研究层可插拔（NotebookLM / Perplexity / 本地模型等）。SOP 以 skills 形式沉淀，用户只需修改配置。

## 设计原则

1. **两端固定，中间可换** — vibe coding 工具 ↔ [研究适配器] ↔ Obsidian
2. **SOP 即 skills** — 工作流沉淀在 SKILL.md 中，不在人脑里
3. **用户只改 config** — vault 路径、工具选择、研究方向、资源来源
4. **session 驱动** — 每次研究 = 一个独立的日期前缀文件夹

## 名字由来

**Khan**（来自 AlmostKhan）+ **note** — Khan 的笔记 / 征服知识领地的笔记。
