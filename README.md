## What is khanote?

khanote connects your vibe coding tools (Claude Code / Cursor / Windsurf / Copilot) with Obsidian, using a pluggable research layer (NotebookLM / Perplexity / local models) in between. SOPs are codified as skills — you only touch config.

## Design Principles

1. **Two ends fixed, middle swappable** — vibe coding tool ↔ [research adapter] ↔ Obsidian
2. **SOP as skills** — workflows live in SKILL.md, not in your head
3. **Config-only for users** — vault path, tools, research domains, sources
4. **Session-driven** — each research run = an independent date-prefixed folder

## Name

**Khan** (from AlmostKhan) + **note** — Khan's notes / notes that conquer knowledge.
